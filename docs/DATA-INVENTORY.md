# Data inventory

Defaults describe the application and included Compose setup. The deployment operator controls service-log retention, any external provider, and any separately managed backups.

| Data item | Where | Why | Retention | How to delete |
| --- | --- | --- | --- | --- |
| User UUID, email, Argon2id password hash, verification flag, created timestamp | Database `users` | Sign-in and contact | Account lifetime | Account and data → Delete my account |
| Workspace UUID, name, owner ID, roles, membership timestamps | Database `workspaces`, `memberships` | Access control | Workspace or membership lifetime | Account deletion removes memberships and the personal workspace |
| Session IDs, user ID, access/refresh/CSRF hashes and timestamps | Database `sessions`; access, refresh and CSRF credentials in browser cookies | Sign-in and CSRF protection | Access 15 minutes, refresh session 7 days. Expired rows swept. | Sign out or delete the account. Password reset removes sessions. Clear cookies on other devices. |
| Account token hash, user ID, purpose and timestamps | Database `account_tokens` | Reset password or verify email | Reset 1 hour, verification 24 hours | Use the link, wait for expiry, or delete the account |
| Invitation ID, workspace/inviter IDs, email, role, token hash and timestamps | Database `invitations` | Join workspace | 7 days | Accept, replace or expire the invite. Account/workspace deletion removes associated invitations. |
| Document IDs, workspace/uploader IDs, filename, bytes, status, timestamps, expiry notice flag | Database `documents` | Workspace list and retention | Free 7 days, paid plans 30 days by default, bounded by deployment settings and at least the configured file lifetime | Delete document, delete uploader/personal workspace, or wait for history expiry |
| Audit ID, document ID, timestamps, progress/check summaries, finding details and short evidence snippets (which may contain Word text) | Database `audits` | Audit history and account export | Document history lifetime | Deleted with document history |
| Repair IDs and applied finding IDs, export IDs and formats, document and actor references, timestamps | Database `fixes`, `exports` | Record repairs and downloads | Document history lifetime | Deleted with document history. On account deletion, surviving rows for other users’ documents lose the deleted actor reference. |
| Original and working DOCX, current audit JSON including finding previews/evidence, working version pointer | Private `A11YRA_DATA_DIR/documents` | Audit, repair and export | 24 hours by default. Downloads leave files available until expiry or explicit deletion. | Delete document, delete uploader/personal workspace, or wait for file expiry |
| Reader ID, document/creator IDs, token hash and timestamps; rendered HTML including document content, assets, optional label and report contact email | Database `reader_shares`; private `A11YRA_DATA_DIR/readers` | Serve a bearer-link snapshot | 1–30 days, capped by document history expiry. It can outlast the working DOCX. | Revoke link, delete document, delete creator/uploader/personal workspace, or wait for expiry |
| API key ID, workspace, name, token hash, created/used/revoked timestamps | Database `api_keys` | Public API access | Workspace lifetime. Revocation disables the key and retains the row. | Revoke for immediate denial. Personal workspace deletion removes its keys. |
| Plan, workspace, Stripe test subscription reference and event timestamp; quota event ID, workspace, kind and created timestamp | Database `subscriptions`, `usage_events` | Enforce plan and quota | Subscription is workspace-scoped. Quota events are swept after 62 days. | Workspace deletion removes rows. Document deletion leaves workspace quota counts. |
| Activity UUID, workspace/actor/target references, action, hashed IP, shortened user agent, timestamps and event fields (role, plan, count or export format) | Database `audit_logs` | Workspace activity and security review | 30 days by default | Expiry sweep. Account deletion clears identifying fields tied to the account and leaves a deletion event. Non-account event references and aggregate history can remain until expiry. |
| Request ID, route template, method, status and duration; generic errors and mail-delivery status | Application service logs; optional Sentry receives a generic failure | Operations and diagnosis | Deployment operator sets sink retention | Operator expires/deletes log records. Application request logs exclude request bodies, document text, filenames, query strings and link tokens. |
| Recipient, subject and account/invite links or expiry notices | SMTP provider and inbox; in development with SMTP disabled, terminal output | Deliver notices and links | Provider, recipient or terminal/log retention | Recipient or operator deletes the copies. Revocation/expiry invalidates applicable links independently. |
| Downloaded repaired DOCX, reader HTML/ZIP, JSON and CSV | Recipient’s device | Portability | Recipient-controlled | Delete the downloaded copies |
| Teacher display settings and reader preferences | Browser local storage | Remember accessibility settings | Until cleared in that browser | Clear this site's browser data |
| Database/file backups | Optional operator-managed storage | Recovery | A11yra creates no automatic backups and sets no backup retention period. The operator sets expiry for any copies. | Operator deletes or expires copies and reapplies deletions before restoring public access. See [operations runbook](OPERATIONS.md). |

Only workspace roles with the required permission can access private workspace data. Anyone holding a valid reader link can open that snapshot. Stripe test checkout is hosted by Stripe. A11yra stores test subscription references and does not receive card details.
