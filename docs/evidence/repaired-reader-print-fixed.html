Stacks and Queues

Two Rules for Removing Items

A stack and a queue can hold the same items and still give you a different next item. In this lecture, you will trace both structures, implement their core operations, and choose the right structure for a task.

What the Interface Promises

An abstract data type specifies the operations you can perform and what they return. A stack lets you insert and remove at the same end. A queue inserts at the rear and removes from the front. You can implement either structure with an array or linked nodes while keeping that rule intact.

One Sequence Two Outcomes

Start empty and insert A, then B, then C. A stack removes C first because C arrived last. A queue removes A first because A arrived first. The next removal is B in both examples, but the third differs again.

Figure 1. The next removal after inserting A, B, and C.

Predict the result if you insert D immediately after the first removal. Under stack rules, D is next. Under queue rules, B is next, because it arrived before C and D.

Stacks and Last In First Out

The accessible end of a stack is the top. Push adds an item there, pop removes and returns the top item, and peek reads it without removal. LIFO means last in, first out.

Trace an Undo History

Imagine editing a text file. You type a heading, insert an example, then delete a sentence. Each edit adds a record to the undo stack. The first undo reverses the sentence deletion, the most recent edit.

Operation Stack bottom to top Result
push(heading) [heading] —
push(example) [heading, example] —
push(delete sentence) [heading, example, del] —
peek() [heading, example, del] delete sentence
pop() [heading, example] delete sentence

Implement a Stack with a List

Use the right end of a Python list as the top. The final index, -1, reads the last element. Call pop without an index to remove from the same end.

stack = []
stack.append("heading")
stack.append("example")
if stack:
print(stack[-1]) # peek: example
print(stack.pop()) # pop: example

Empty and Full States

Popping an empty stack is underflow. Python raises IndexError, so either check for an empty stack or document that your function raises. A fixed-capacity stack can also reject a push when it is full. With a dynamic array, push is amortized O(1) because an occasional resize copies the existing elements. Peek and removing the final item are O(1) for ordinary operations.

Queues and First In First Out

A queue has a front and a rear. Enqueue adds at the rear, dequeue removes and returns the front item, and front reads the next item without removing it. FIFO means first in, first out.

Trace a Print Queue

Mina submits a one-page handout, Dev submits a worksheet, and Jo submits a lab report. The printer takes Mina’s job first. If Ravi submits a job while Mina’s is printing, Ravi joins behind Jo. FIFO orders jobs by arrival, regardless of their length.

Implement a Queue with a Deque

from collections import deque

jobs = deque(["Mina", "Dev", "Jo"])
if jobs:
next_job = jobs[0] # peek: Mina
running = jobs.popleft()
jobs.append("Ravi")

Appending to the right and removing from the left of a deque are O(1). A list with pop(0) must shift the remaining elements, so that removal is O(n). Use the deque’s two ends to avoid moving the rest of the queue.

Circular Queues and Wraparound

A circular queue stores items in a fixed-length array and reuses slots freed by earlier removals. Let head be the next read index, tail the next write index, and size the number of stored items. Begin with head, tail, and size all equal to zero.

Update the Indices

After writing or reading a slot, advance the corresponding index by one modulo capacity. With capacity four, advancing from index 3 returns index 0. Size distinguishes an empty queue from a full one even when head and tail are equal.

enqueue(x):
if size == capacity: report full
slots[tail] = x
tail = (tail + 1) % capacity
size += 1

dequeue():
if size == 0: report empty
item = slots[head]
slots[head] = empty
head = (head + 1) % capacity
size -= 1
return item

Trace a Wrapped State

With four slots, enqueue A, B, C, and D, then dequeue twice. The remaining logical order is C, D and head is 2. Enqueue E at index 0 and F at index 1. The physical array now reads E, F, C, D, while the logical order is C, D, E, F.

All core operations are O(1) because they touch one slot and a few counters. The backing array occupies O(capacity) space. In a language with references, clearing a vacated slot lets an otherwise unreferenced object be reclaimed.

Bracket Matching with a Stack

Read the expression from left to right. Push each opening bracket. On a closing bracket, pop and check whether the types match. An empty stack at that point means the closer has no opener. After the last character, any brackets left on the stack are unmatched.

In ([)] the first closing bracket is a parenthesis, but the current top is a square bracket. The expression is therefore invalid even though it contains one opener and one closer of each type.

Breadth First Search with a Queue

Enqueue the starting vertex and mark it visited. While the queue has entries, dequeue a vertex and enqueue each unvisited neighbor, marking each when it is enqueued. Vertices at distance one are processed before vertices at distance two. In an unweighted graph, this explores vertices in order of shortest distance from the start.

For a graph with edges from A to B and C, and from B to D, the visit order is A, B, C, D when neighbors are listed alphabetically. Marking vertices on enqueue prevents two neighbors from scheduling the same vertex twice.

Practice and Review

Work through the three exercises before reading the answers. Write the returned values and the final state so you can check both the order and what remains.

Exercises

  1. Start with an empty stack. Push 4, push 7, pop, push 9, peek, then pop. What does each read or removal return, and what is left?
  2. Start with an empty queue. Enqueue 4, enqueue 7, dequeue, enqueue 9, read the front, then dequeue. What does each read or removal return, and what is left?
  3. Use a circular queue of capacity three. Enqueue X and Y, dequeue once, then enqueue Z and W. List the physical slots from index 0 and the logical order from the front.

Answers

1. Pop returns 7. Peek returns 9, and the second pop also returns 9. The stack contains [4].

2. Dequeue returns 4. Reading the front returns 7, and the second dequeue also returns 7. The queue contains [9].

3. The physical slots are [W, Y, Z]. Head and tail both point to index 1, and size is 3. The logical order is Y, Z, W.
